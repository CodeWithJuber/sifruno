# Disposable controller-death qualification

This Windows host harness builds and admits the current Go driver, then uses a
fresh overlay of the already verified offline Alma 9.8 fixture. It is a test
tool, not a production hosting route, installer or cPanel compatibility claim.

From the assigned integration worktree, with the primary workspace passed as
an absolute argument:

```text
node lab/hostwebruntime-crash-host/freeze.mjs <primary-workspace>
node lab/hostwebruntime-crash-host/run.mjs <primary-workspace> --check-only
node lab/hostwebruntime-crash-host/run.mjs <primary-workspace> --prepare-only
node lab/hostwebruntime-crash-host/run.mjs <primary-workspace>
```

Actual execution follows independent source review and completed ISO readback.
The installed Go wrapper establishes compiler authority; the same pinned Go
tool builds with an owned cache and read-only offline module inputs. The source
catalog conservatively pins selected project, dependency and standard-library
sources, including selected package test sources. A broad source inventory is
not a claim that every listed test executes. ELF64 AMD64 binaries and the exact
Linux driver test inventory have separate hashes.

The prior fixture is admitted as an immutable setup library. Its canonical
UTF-8 bytes are verified after explicitly measured CRLF normalization; its old
main, driver, source manifest and native-success receipt are never used. The
new wrapper owns schema 2, admission, markers, current source/ELF provenance,
counter/death evidence and cleanup. The independent receipt auditor reconstructs
Apply/repair/event digests and the selective alpha static/PHP body. HTTP
measurements are made by the driver; rechecking their contract is not a second
network observer. The guest separately scans recorded namespace extinction.

No external NIC, host shares, inherited QEMU configuration, display or monitor
is enabled. One CPU/1536 MiB and 600 seconds/2 MiB serial output are hard bounds.
Only the launched QEMU child is terminated. Prepared images, tools, packages and
all admitted source/payload pins are checked before and after; failed overlays
and receipts remain separate. The host never mutates the running panel state,
primary dependencies or firewall.

The fixture explicitly adapts NSS to files-only and disables default mail-spool
creation. Direct root-driver and synthetic inventory leases are test authority;
they do not qualify stock provisioning or the production broker. This single
death window does not certify disk/fsync faults, reboot, all transition faults,
hostile tenant/SELinux domain policy, capacity, release archives, authenticated
API composition, original vendor clients or all OS families.

Recovery is a revert of these unactivated lab commits and disposal only of the
owned overlay after evidence review. Ambiguous product journal state is never
deleted or downconverted.
