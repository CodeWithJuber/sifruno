## How to sign

The first time you open a pull request, the CLA check posts a comment that
links to this document. To sign, reply on that pull request with exactly:

> I have read the CLA Document and I hereby sign the CLA

The check records your GitHub user name and ID, the pull request and the
time in the `cla-signatures` branch of this repository. One signature covers
all your future Contributions to Sifruno under this version of the
agreement.
